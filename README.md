# 🏥 Hospital Data Analysis & Interactive Dashboard using Excel

## 📌 Project Overview

This project focuses on cleaning, analyzing, and visualizing hospital data using Microsoft Excel. The objective was to transform raw healthcare data into a structured and meaningful dataset and create an interactive dashboard for better analysis.

## 🛠️ Tools & Techniques Used

* Microsoft Excel
* Data Cleaning
* Excel Formulas and Functions
* Pivot Tables
* Pivot Charts
* Slicers
* Conditional Formatting
* Data Visualization
* Interactive Dashboard

## 🧹 Data Cleaning

The raw hospital dataset was cleaned and prepared for analysis. The process included:

* Handling missing values
* Removing duplicate records
* Standardizing data
* Correcting inconsistent values
* Validating patient information
* Creating additional calculated columns
* Preparing structured data for analysis

## 📊 Data Analysis

Pivot Tables were used to analyze hospital data and identify patterns across different categories such as:

* Departments
* Patient age groups
* Billing amounts
* Test results
* Doctor records
* Lab records

## 📈 Interactive Dashboard

An interactive Excel dashboard was created using Pivot Charts and Slicers to make the analysis easy to explore and understand.

The dashboard allows users to filter and analyze hospital data dynamically.

## 📂 Workbook Structure

* **Raw_Data** – Original hospital dataset
* **Cleaned_Data** – Cleaned and transformed dataset
* **Pivot_Table** – Pivot-based analysis
* **Dashboard** – Interactive data visualization dashboard
* **Doctor_Conference** – Doctor-related records
* **Lab_Record** – Laboratory records

## 🎯 Project Objective

The main objective of this project was to practice the complete Excel data analysis workflow:

**Raw Data → Data Cleaning → Data Analysis → Pivot Tables → Data Visualization → Interactive Dashboard**
